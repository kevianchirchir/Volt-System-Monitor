Volt is a desktop system monitoring application designed to make tracking your PC's performance simple, accessible, and visually appealing.

Monitor your hardware in real time, explore system statistics, and keep an eye on the resources powering your machine — all from one centralized dashboard.

Features

  CPU Monitoring — Track processor utilization in real time.
  
  GPU Monitoring — Keep tabs on graphics performance and temperature.
  
  Memory Monitoring — Monitor RAM usage and availability.
  
  Disk Monitoring — Keep track of storage utilization.
  
  Network Monitoring — View upload and download activity in real time.
  
  Live Dashboard — Access system statistics through a clean, modern interface.


AI tools were used to assist with portions of the GUI development. 
Core application logic, system monitoring functionality, and project 
architecture were developed and integrated as part of the learning process.
